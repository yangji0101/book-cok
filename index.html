📤 이 카드를 친구에게

🔓 이 링크를 받은 사람은 누구나 이 카드를 볼 수 있습니다. 링크 안에 카드 내용이 통째로 들어 있어서, 한 번 보내면 되돌릴 수 없습니다. 남에게 보이면 안 되는 생각은 빼고 보내세요.

🔧 관리자

🔓 이 암호는 비밀이 아닙니다. 앱이 파일 하나로 되어 있어서, 마음먹고 들여다보면 누구나 찾을 수 있습니다. 문을 잠그는 자물쇠가 아니라 「관계자 외 출입금지」 팻말이라고 생각하세요. 성적처럼 지켜야 할 것은 이 앱에 넣지 마세요.

📦 기록 백업 · 옮기기

기기를 바꾸거나 실수로 지웠을 때를 대비해 통째로 복사해 둡니다. 아래 글자를 전부 복사해서 메모장에 붙여 두세요.

📊 모인 카드 (반 취합)

친구 책장에 담긴 카드를 표로 뽑습니다. 엑셀에 붙여넣으면 그대로 표가 됩니다.

🌐 서버는 아직 없습니다

이 앱은 파일 하나로 되어 있어 서버가 없습니다. 그래서 「서버 관리」로 할 수 있는 일이 아직 없습니다. 기록은 각자의 기기 안에만 있고, 관리자도 남의 기기 안은 볼 수 없습니다.

지금 되는 것학교 목록 정하기 · 이 기기 백업 · 카드로 모으기 서버가 있어야 되는 것반 전체 실시간 순위 · 선생님이 모두의 기록 보기 · 기기를 바꿔도 따라오는 기록 서버를 붙이려면무료 데이터베이스(파이어베이스 등) 계정과 로그인이 필요합니다. 그때는 이 화면이 진짜 관리자 화면이 됩니다.

⚠️ 위험한 단추

이 기기에 저장된 내 칸의 기록을 전부 지웁니다. 되돌릴 수 없습니다.

🏫 반별로 등록시키기

학생마다, 반마다 주소를 따로 만들 필요가 없습니다. 주소 하나만 나눠주면 학생이 학교 → 학년 → 반 → 이름 을 골라 등록합니다. 한 번만 하면 그다음부터는 홈 화면 아이콘으로 바로 들어갑니다.

1. 모두에게 나눠줄 주소 — 이것 하나면 됩니다
2. 학교 목록 넣어 두기

우리 학교를 목록에 넣어 두면 학생이 눌러서 고릅니다. 넣지 않아도 학생이 직접 칠 수 있습니다.

3. 반을 정해서 보내고 싶을 때 (선택)

이 주소로 들어오면 반이 이미 정해져 있어서 이름만 넣으면 됩니다.

다른 반 주소는 위쪽 🏫 단추로 반을 바꾼 뒤 다시 복사하세요. 아래 태그 주소에도 반이 자동으로 따라갑니다.

🍎 아이폰 · 단축어

폰이 방해금지를 켜고, 앱이 시간을 잽니다. 웹은 방해금지를 못 켭니다 — 그래서 단축어에 맡깁니다.

1. 단축어 앱 → ＋ → 이름 독서 시작
  1. 동작 집중 모드 설정 → 방해금지 → 켬
  2. 동작 URL 열기 → 아래 주소
2. 단축어 하나 더 → 이름 독서 끝
  1. 동작 집중 모드 설정 → 방해금지 → 끔
  2. 동작 URL 열기 → 아래 주소
3. 자동화 → 새로 만들기 → NFC
  1. 스캔을 누르고 스티커를 폰 위쪽 모서리에 댑니다
  2. 동작은 단축어 실행 → 독서 시작
  3. 실행 전 확인을 끕니다 — 안 끄면 매번 물어봅니다
이름이 한 글자만 달라도 안 됩니다. 독서 시작 · 독서 끝 — 붙여쓰기(독서시작)나 독서 종료 는 실패합니다.
중단 및 출력 동작이 있으면 지웁니다. 매번 허용을 묻습니다.
URL 과 URL 열기 는 다른 동작입니다. 끝에 열기 가 붙은 것이 맞습니다.

아이폰 스티커에는 아무것도 안 써도 됩니다. 자동화가 태그의 고유번호만 읽습니다.

🤖 안드로이드

안드로이드는 단축어가 없습니다. 태그가 주소를 들고 있어야 하고, 방해금지는 매크로 앱이 켭니다.

0. 먼저 준비할 것
내 폰이 NFC 되는가 설정에서 NFC 를 검색합니다. 안 나오면 이 폰은 태그를 못 읽습니다 — 앱은 그대로 쓰고 홈 화면 아이콘으로 엽니다.
NFC 켜기설정 → 연결 → NFC 켬. 꺼져 있으면 태그를 대도 아무 일도 없습니다.
NFC Tools플레이스토어 · 무료. 태그에 주소를 써 넣는 데만 씁니다. 한 번 쓰고 나면 지워도 됩니다.
MacroDroid플레이스토어 · 무료(매크로 5개까지). 방해금지를 켜는 일을 합니다. Automate 로 대신해도 됩니다.
방해금지 접근 권한MacroDroid 안에서 처음 한 번 허용합니다. 이걸 안 주면 매크로가 도는데 방해금지만 안 켜집니다.
크롬이미 깔려 있습니다. 태그가 여는 것이 크롬입니다.

태그만 쓰고 방해금지는 손으로 켜겠다면 NFC Tools 하나면 됩니다.

1. 먼저 읽어 봅니다 — 어디에 대야 하는지 익히는 과정입니다
  1. NFC Tools 앱 (만든 곳 wakdev, 비슷한 이름이 많습니다)
  2. 아래 탭 읽기 → 가운데 스캔
  3. 태그를 폰 뒷면 중앙~위쪽에 댑니다. 기종마다 달라서 위아래로 천천히 훑습니다
  4. 삑 하고 NTAG213 같은 종류와 용량이 뜨면 살아 있는 태그입니다

반응이 없으면 — 댄 자리를 바꿔서 다시 / 두꺼운 케이스는 빼고 / 설정에서 NFC가 켜져 있는지 / 금속 위에 붙은 태그는 잘 안 읽힙니다.

2. 주소 써 넣기
  1. 탭 쓰기 → 레코드 추가
  2. 긴 목록에서 URL/URI 를 찾아 누릅니다 (Text·이메일·전화 사이에 있습니다)
  3. 아래 주소를 붙여넣고 확인 → 목록에 한 줄이 생깁니다
  4. 아래 쓰기 버튼 → 태그를 아까 그 자리에 댑니다
  5. 쓰기 완료 가 뜨면 끝입니다
⚠️ 레코드 추가까지만 하고 멈추면 태그에는 아무것도 안 들어갑니다. 목록에 생긴 줄은 앱 안의 임시 목록일 뿐이라, 앱을 껐다 켜면 사라집니다. 그건 고장이 아닙니다.
반드시 맨 아래 「쓰기」 버튼을 누르고 태그를 1~2초 대고 있어 「쓰기 완료」를 봐야 끝입니다.

확인 — 읽기 탭에서 다시 스캔해서 방금 쓴 주소가 보이면 됐습니다.

⛔ 기타(Other) 탭의 「태그 잠금(Lock tag)」은 절대 누르지 않습니다. 한 번 누르면 그 태그는 영원히 못 고칩니다. 되돌릴 방법이 없습니다.
3. 실제로 태그해 보기
  1. NFC Tools 앱을 닫습니다. 켜 두면 앱이 태그를 가로챕니다
  2. 잠금을 풀고 홈 화면에서 태그를 댑니다. 잠금화면에서는 안 됩니다
  3. 안드로이드는 크롬이 바로 열립니다 (아이폰은 화면 위 배너를 손으로 눌러야 열립니다)
  4. 이 앱이 뜨고 독서 화면으로 바로 들어가면 성공입니다

아무 배너도 없이 그냥 앱만 열리면 주소에서 ?src=nfc 가 빠진 것입니다. 연달아 두 번 대면 안 읽힐 수 있습니다 — 화면을 껐다 켜고 다시 댑니다.

4. 방해금지까지 자동으로 — MacroDroid

여기까지 안 해도 앱은 씁니다. 방해금지를 손으로 켜기 싫은 사람만 합니다.

  1. MacroDroid 설치 → 첫 화면에서 매크로 추가
  2. 트리거 ＋ → 연결성 → NFC 태그 → 태그를 폰에 대서 등록합니다
    태그의 고유번호로 알아봅니다. 태그에 뭘 더 쓸 필요는 없습니다.
  3. 동작 ＋ → 볼륨 → 방해 금지 모드 → 켜기
    기종에 따라 「우선 순위 모드」로 되어 있습니다. 같은 것입니다.
  4. 저장하고 이름을 붙입니다 (예: 독서 시작)
  5. 처음 한 번 방해 금지 접근 권한을 허용합니다 — 앱이 설정 화면으로 데려다 줍니다
동작에 「웹페이지 열기」는 넣지 않습니다. 태그가 이미 주소를 들고 있어서 크롬이 두 번 열립니다. 여는 일은 태그가, 방해금지는 MacroDroid가 — 이렇게 나눕니다.
배터리 최적화에서 MacroDroid를 제외해야 폰이 자고 있어도 돕니다. 설정 → 배터리 → 앱별 관리에서 제한 없음으로 둡니다.
무료판은 매크로 5개까지입니다. 우리는 하나만 쓰니 넉넉합니다.
끄는 것은 손으로 합니다. 화면 위에서 아래로 쓸어내려 방해금지 아이콘을 누릅니다. 웹은 안드로이드의 방해금지를 끌 수 없습니다 — 앱이 기록 화면에서 이 안내를 띄웁니다.
태그가 안 읽히면 설정에서 NFC가 켜져 있는지, 폰 뒷면 어디에 대야 하는지 확인합니다.
매크로가 도는데 방해금지만 안 켜지면 접근 권한이 빠진 것입니다. 잠금을 푼 상태에서만 NFC가 읽힙니다.
