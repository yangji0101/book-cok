# 청소년 아르바이트와 근로기준법 — 2쪽 발표자료 (초안)

법과 사회 수행평가용 HyperFrames 슬라이드 덱입니다. 슬라이드 2장, 발표자 노트 포함.

| | |
|---|---|
| **1쪽** | 미성년자라고 시급을 깎는 것은 합의해도 무효다 — 2026년 최저임금 10,320원, 나이·시간·야간 규정 |
| **2쪽** | 떼인 알바비는 신고하면 돌려받을 수 있다 — 증거 → 1350 상담 → 진정 접수 |

미리보기 이미지는 `preview/slide-1.png`, `preview/slide-2.png`.

## 발표하는 법

```bash
npm run dev        # 발표 모드 서버가 뜨고 브라우저가 열린다
```

- **← →** 또는 **Space** 로 넘긴다. 한 장 안에서도 항목이 하나씩 나타난다(1쪽 3개, 2쪽 4개).
- **P** 를 누르거나 화면 아래 **Present** 버튼을 누르면 청중용 탭이 새로 열리고, 원래 탭은 **발표자 화면**(다음 장 미리보기 + 발표자 노트 + 경과 시간)이 된다.
- 발표자 노트는 발표자 화면에서 바로 고칠 수 있다. 고친 내용은 그 브라우저에 저장된다.
- 화면 공유로 발표한다면 **청중용 탭만** 공유한다. 구글 미트는 `탭 공유`, 줌은 청중 탭을 창으로 떼어내 그 창을 공유.

Node.js 22 이상이 필요합니다. 아이패드에서는 실행되지 않으니 노트북·데스크톱에서 열어야 합니다.

## 고치는 법

- 문구·색·배치는 전부 `index.html` 한 파일 안에 있습니다. 슬라이드 1은 `data-composition-id="rights"`, 슬라이드 2는 `"action"` 구역.
- 발표자 노트와 항목이 나타나는 시점은 파일 맨 위 `application/hyperframes-slideshow+json` 블록의 `notes`, `fragments` 에 있습니다.
- 고친 뒤에는 검사를 돌립니다: `npm run check` (글자 겹침, 대비, 애니메이션까지 확인해 줍니다.)
- 문구를 많이 바꿨다면 `npm run font` — 이 덱에 쓰인 글자만 담은 서브셋 글꼴을 다시 받아 넣습니다. 안 돌리면 새로 넣은 글자만 다른 글꼴로 보일 수 있습니다.
