# 백색소음 넣는 곳

여기에 mp3 파일을 넣으면 앱이 **직접 만든 소리 대신 이 파일을 씁니다.**
파일이 없으면 앱이 소리를 만들어 냅니다 — 그래서 지금도 소리는 납니다.

## 파일 이름

| 파일 | 버튼 |
|---|---|
| `rain.mp3` | 🌧️ 빗소리 |
| `cafe.mp3` | ☕ 카페 |
| `forest.mp3` | 🌲 숲 |
| `wave.mp3` | 🌊 파도 |

## 규칙

- **mp3**, 30초 ~ 2분이면 충분합니다 (앱이 계속 이어서 반복합니다)
- **처음과 끝이 이어지게** 만들면 반복할 때 툭 끊기지 않습니다
- 한 파일 **2MB 아래**로 (폰에서 빨리 받아야 합니다)
- 소리 크기는 앱이 알아서 줄입니다. 너무 작게 만들지 마세요

## 소리가 안 들린다고 할 때

앱 안 **독서 화면 ▸ 🔎 소리 확인** 을 누르면 앱이 직접 재서 알려 줍니다.

- 「소리는 나가고 있습니다」 → **폰 문제**입니다. 아이폰 옆면 **무음 스위치**를 확인하세요.
  무음이면 이 앱 소리는 아예 안 납니다. 웹은 이것을 넘을 수 없습니다.
- 「소리가 나가지 않고 있습니다」 → 소리 버튼을 한 번 더 눌러 주세요.
