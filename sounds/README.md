# 백색소음

**소리 세 개가 이미 들어 있습니다.** 앱이 직접 만들어 넣은 파일입니다.

| 파일 | 버튼 | 무슨 소리 |
|---|---|---|
| `rain.mp3` | 🌧️ 비 | 빗줄기가 굵어졌다 가늘어지고, 물방울이 톡톡 떨어집니다 |
| `forest.mp3` | 🌲 숲 | 바람에 잎이 스치고, 이따금 새가 지저귑니다 |
| `sea.mp3` | 🌊 바다 | 8초에 한 번 파도가 밀려오고 거품이 잦아듭니다 |

셋 다 **48초 · 96kbps · 563KB** 입니다. 앱이 계속 이어서 반복합니다.

## 반복해도 왜 안 끊기나

소리를 「주파수 영역」에서 만들었습니다. 그렇게 만들면 소리의 주기가 파일
길이와 똑같아져서 **끝과 처음이 저절로 이어집니다.** 물방울·새소리처럼
시간축에 얹는 소리도 끝을 넘어가면 처음으로 되감아 붙였습니다.
재생할 때 앞뒤 0.06초를 잘라내서 mp3 특유의 무음까지 건너뜁니다.

## 바꾸고 싶으면

같은 이름으로 덮어쓰면 됩니다. 코드는 안 고쳐도 됩니다.
파일을 **지우면** 앱이 그 자리에서 소리를 직접 만들어 냅니다 — 그래서
파일이 없어도 소리는 납니다.

- **mp3**, 30초 ~ 2분 · 한 파일 **2MB 아래**
- **처음과 끝이 이어지게** 만들면 반복할 때 툭 끊기지 않습니다
- 소리 크기는 앱이 알아서 맞춥니다. 너무 작게 만들지 마세요

소리를 만든 프로그램은 `scratchpad/sound.py` 에 남겨 두었습니다.

## 이름을 바꾸거나 개수를 늘리려면

`index.html` 의 `NOISES` 표만 고치면 버튼도 같이 바뀝니다.
새 소리를 추가할 땐 만드는 함수(`makeRain` 같은 것)도 하나 있어야
파일이 없을 때 대신 낼 소리가 생깁니다.

## 소리가 안 들린다고 할 때

앱 안 **독서 화면 ▸ 🔎 소리 확인** 을 누르면 앱이 직접 재서 알려 줍니다.

- 「소리는 나가고 있습니다」 → **폰 문제**입니다. 아이폰 옆면 **무음 스위치**를 확인하세요.
  무음이면 이 앱 소리는 아예 안 납니다. 웹은 이것을 넘을 수 없습니다.
- 「소리가 나가지 않고 있습니다」 → 소리 버튼을 한 번 더 눌러 주세요.
