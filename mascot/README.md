# 마스코트 그림

**지금은 그림이 들어 있습니다.** 앱을 열면 이모지 대신 이 그림들이 나옵니다.

- 🦔 **솔이** · 🐷 **꿀이** — 보내 주신 키링 그림에서 오려낸 것
- 🌰 씨앗 · 🌱 새싹 · 🌿 떡잎 · 옷 5종 — 키링 그림의 색과 선 굵기에 맞춰 그린 것

마음에 안 들면 **같은 이름으로 덮어쓰기만 하면 됩니다.** 코드는 안 고쳐도 됩니다.

## 규칙

- **512 × 512 png**, 배경 **투명**
- 캐릭터는 가운데, 아래 여백 28px (지금 그림들이 그렇게 맞춰져 있습니다)
- 옷은 **캐릭터와 똑같은 512 칸에 옷만** 그리고 나머지 투명
  → 겹쳤을 때 위치가 저절로 맞습니다

## 파일

### 자라는 단계 — 공통

| 파일 | 언제 |
|---|---|
| `seed.png` | 🌰 씨앗 · 기록 0개 |
| `sprout.png` | 🌱 새싹 · 기록 1개 |
| `leaf.png` | 🌿 떡잎 · 기록 3개 |

### 🦔 솔이 (고슴도치) · 🐷 꿀이 (돼지)

| 파일 | 언제 | 지금 그림 |
|---|---|---|
| `sol-1.png` / `kkul-1.png` | 기록 6개 · 아기 | 캐릭터 + 옆에 새싹 |
| `sol-2.png` / `kkul-2.png` | 기록 10개 | 캐릭터만 |
| `sol-3.png` / `kkul-3.png` | 기록 15개 | 캐릭터 + 옆에 책 |
| `sol-4.png` / `kkul-4.png` | 기록 22개 · 다 자람 | 캐릭터 + 반짝임 |

> 홈 화면의 두 친구는 `sol-4.png` 와 `kkul-4.png` 를 씁니다.
> 지금은 네 단계가 **같은 자세**에 장식만 다릅니다. 단계마다 다른 그림을
> 그리시면 그대로 덮어쓰면 됩니다.

### 옷 · 소품

옷은 캐릭터마다 얼굴·목 위치가 달라서 **캐릭터별로 한 장씩** 있습니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `wear-<옷>-sol.png` | 솔이가 입을 때 |
| `wear-<옷>-kkul.png` | 꿀이가 입을 때 |
| `wear-<옷>.png` | 캐릭터별 그림이 없을 때 쓰는 공용 |
| `wear-<옷>-icon.png` | 옷장 목록에 보이는 작은 그림 (256×256) |

`<옷>` 은 `scarf` `hat` `glasses` `ribbon` `crown` 다섯입니다.

| 옷 | 열리는 조건 |
|---|---|
| 🧣 목도리 | 기록 6개 |
| 🎩 모자 | 완독 1권 |
| 👓 안경 | 기록 15개 |
| 🎀 리본 | 완독 3권 |
| 👑 왕관 | 기록 22개 |

> 캐릭터별로 나누기 싫으면 `wear-<옷>.png` 하나만 두고 나머지를 지우면 됩니다.
> 그러면 두 친구가 같은 그림을 씁니다.
