# 마스코트 그림 넣는 곳

**꿀이(돼지)** 와 **솔이(고슴도치)** 그림을 여기에 넣습니다.
넣기만 하면 앱이 알아서 씁니다 — **코드는 안 고쳐도 됩니다.**
파일이 없으면 이모지가 대신 나오므로, 한 장씩 넣어도 앱은 계속 잘 돕니다.

## 어떻게 자라나

```
씨앗 → 새싹 → 떡잎          ← 여기까지는 둘 다 같습니다
        ↓  기록 6개가 되면 갈림길
   솔이(고슴도치)  또는  꿀이(돼지)   ← 학생이 고릅니다
        ↓  4단계까지 자랍니다
```

## 규칙

- **512 × 512 png**, 배경은 **투명**
- 캐릭터는 칸 가운데에, 위아래 약간 여백
- 옷·소품은 **캐릭터와 똑같은 512 × 512 칸에 그것만** 그리고 나머지는 투명하게
  → 그래야 겹쳤을 때 위치가 저절로 맞습니다

## 파일 이름

### 공통 — 아직 누구인지 정해지기 전

| 파일 | 언제 | 지금 나오는 이모지 |
|---|---|---|
| `seed.png` | 씨앗 · 기록 0개 | 🌰 |
| `sprout.png` | 새싹 · 기록 1개 | 🌱 |
| `leaf.png` | 떡잎 · 기록 3개 | 🌿 |

### 🦔 솔이 — 고슴도치, 돋보기를 든 탐정

| 파일 | 언제 | 이름 |
|---|---|---|
| `sol-1.png` | 기록 6개 | 아기 솔이 (가시가 뾰족 올라왔어요) |
| `sol-2.png` | 기록 10개 | 솔이 (교복을 입고 학교에 갔어요) |
| `sol-3.png` | 기록 15개 | 안경 쓴 솔이 (돋보기로 문장을 파고들어요) |
| `sol-4.png` | 기록 22개 | 박사 솔이 |

### 🐷 꿀이 — 돼지, 머리에 꽃을 단 이야기꾼

| 파일 | 언제 | 이름 |
|---|---|---|
| `kkul-1.png` | 기록 6개 | 아기 꿀이 (머리에 꽃이 폈어요) |
| `kkul-2.png` | 기록 10개 | 꿀이 (교복을 입고 학교에 갔어요) |
| `kkul-3.png` | 기록 15개 | 책 읽는 꿀이 (초록 책을 끼고 다녀요) |

> 홈 화면의 두 친구 그림은 `sol-4.png` 와 `kkul-4.png` 를 씁니다.

### 옷·소품 (투명 배경, 그것만)

| 파일 | 언제 열리나 |
|---|---|
| `wear-scarf.png` | 목도리 · 기록 6개 |
| `wear-hat.png` | 모자 · 완독 1권 |
| `wear-glasses.png` | 안경 · 기록 15개 |
| `wear-ribbon.png` | 리본 · 완독 3권 |
| `wear-crown.png` | 왕관 · 기록 22개 |

**옷은 솔이와 꿀이가 같이 씁니다.** 두 캐릭터의 머리·목 위치를 비슷하게 그리면
옷 한 장으로 둘 다 됩니다. 따로 하고 싶으면 알려주세요 — 캐릭터별 옷으로 바꿔 드립니다.

> 키링 그림처럼 **교복은 캐릭터에 이미 그려 넣어도 됩니다.** 옷장의 옷은
> 그 위에 덧붙이는 소품(목도리·모자·왕관 같은 것)으로 쓰면 자연스럽습니다.
