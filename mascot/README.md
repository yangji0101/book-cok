# 마스코트 그림

**그림이 들어 있습니다.** 앱을 열면 이모지 대신 이 그림들이 나옵니다.
씨앗에서 시작해 **열 걸음**을 거쳐 솔이나 꿀이가 됩니다.

- 🦔 **솔이** · 🐷 **꿀이** — 보내 주신 키링 그림에서 오려낸 것
- 🌰 씨앗 · 🌱 새싹 · 🌿 떡잎 · 🌷 꽃봉오리 — 키링 그림의 색과 선 굵기에 맞춰 그린 것

마음에 안 들면 **같은 이름으로 덮어쓰기만 하면 됩니다.** 코드는 안 고쳐도 됩니다.

## 규칙

- **512 × 512 png**, 배경 **투명**
- 캐릭터는 가운데, 아래 여백 28px (지금 그림들이 그렇게 맞춰져 있습니다)

## 열 걸음

### 1 ~ 4 걸음 — 누구나 똑같이

| 파일 | 이름 | 언제 |
|---|---|---|
| `seed.png` | 씨앗 | 기록 0개 |
| `sprout.png` | 새싹 | 기록 1개 |
| `leaf.png` | 떡잎 | 기록 3개 |
| `bud.png` | 꽃봉오리 | 기록 5개 |

### 5 ~ 10 걸음 — 고른 친구로

기록 **7개**가 되면 꽃봉오리에서 친구가 나옵니다. 솔이와 꿀이 중 하나를
고르고, 그 뒤로는 그 친구로 자랍니다. (나중에 바꿔도 단계는 그대로입니다.)

| 파일 | 걸음 | 언제 | 이름 |
|---|---|---|---|
| `sol-1.png` / `kkul-1.png` | 5 | 기록 7개 | 수줍은 솔이 / 꿀이 |
| `sol-2.png` / `kkul-2.png` | 6 | 기록 10개 | 아기 솔이 / 꿀이 |
| `sol-3.png` / `kkul-3.png` | 7 | 기록 14개 | 솔이 / 꿀이 |
| `sol-4.png` / `kkul-4.png` | 8 | 기록 19개 | 씩씩한 솔이 / 꿀이 |
| `sol-5.png` / `kkul-5.png` | 9 | 기록 25개 | 책벌레 솔이 / 꿀이 |
| `sol-6.png` / `kkul-6.png` | 10 | 기록 32개 | 박사 솔이 / 꿀이 |

> 홈 화면 인사말 옆의 두 친구는 **고른 쪽은 지금 모습**, 안 고른 쪽은
> 다 자란 모습(`sol-6` / `kkul-6`)을 흐리게 보여 줍니다.

아직 친구를 안 골랐으면 성장 화면의 5~10 걸음 칸은 **❔ ???** 로 보입니다.
무엇이 나올지 모르는 채로 자라는 편이 더 기다려지기 때문입니다.

## 옷 입히는 기능은 없앴습니다

예전에는 목도리·모자 같은 것을 입힐 수 있었지만, 칸만 해금되는 느낌이라
**자라는 것 하나에 집중하도록** 지웠습니다. `wear-*.png` 는 모두 삭제했습니다.

## 단계 수나 이름을 바꾸려면

`index.html` 의 `COMMON` · `PATHS` · `SPLIT_AT` 만 고치면 됩니다.
`allSteps()` 가 걸음 수를 알아서 다시 셉니다.
