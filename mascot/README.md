# 마스코트 그림 넣는 곳

여기에 png 파일을 넣기만 하면 앱이 알아서 씁니다. **코드는 안 고쳐도 됩니다.**
파일이 없으면 이모지가 대신 나오므로, 한 장씩 넣어도 앱은 계속 잘 돕니다.

## 규칙

- **512 × 512 png**, 배경은 **투명**
- 캐릭터는 칸 가운데에, 위아래 약간 여백
- 옷은 **캐릭터와 똑같은 512 × 512 칸에 옷만** 그리고 나머지는 투명하게
  → 그래야 겹쳤을 때 위치가 저절로 맞습니다

## 파일 이름

### 공통 (씨앗 단계 — 아직 누구인지 정해지기 전)

| 파일 | 언제 |
|---|---|
| `seed.png` | 씨앗 · 기록 0개 |
| `sprout.png` | 새싹 · 기록 1개 |
| `leaf.png` | 떡잎 · 기록 3개 |

### 솔이 (나무로 자라는 길)

| 파일 | 언제 |
|---|---|
| `sol-1.png` | 아기 솔이 · 기록 6개 |
| `sol-2.png` | 솔이 · 기록 10개 |
| `sol-3.png` | 큰 솔이 · 기록 15개 |
| `sol-4.png` | 숲이 된 솔이 · 기록 22개 |

### 국이 (꽃으로 피는 길)

| 파일 | 언제 |
|---|---|
| `kuk-1.png` | 아기 국이 · 기록 6개 |
| `kuk-2.png` | 국이 · 기록 10개 |
| `kuk-3.png` | 활짝 국이 · 기록 15개 |
| `kuk-4.png` | 꽃밭이 된 국이 · 기록 22개 |

### 옷 (투명 배경, 옷만)

| 파일 | 언제 열리나 |
|---|---|
| `wear-scarf.png` | 목도리 · 기록 6개 |
| `wear-hat.png` | 모자 · 완독 1권 |
| `wear-glasses.png` | 안경 · 기록 15개 |
| `wear-ribbon.png` | 리본 · 완독 3권 |
| `wear-crown.png` | 왕관 · 기록 22개 |

**옷은 솔이와 국이가 같이 씁니다.** 두 캐릭터의 머리·목 위치를 비슷하게 그리면
옷 한 장으로 둘 다 됩니다. 다르게 하고 싶으면 알려주세요 — 캐릭터별 옷으로 바꿔 드립니다.

## 단계 수나 이름을 바꾸고 싶으면

`index.html` 의 `COMMON`, `PATHS`, `WEARS` 표만 고치면 됩니다.
